# Effzeh News – 1. FC Köln Nachrichten

Automatisierter News-Blog für den 1. FC Köln.
Scannt alle 4 Stunden 9 Quellen und generiert KI-Zusammenfassungen.

## Quellen

- fc.de – Offizielle Vereinsnachrichten
- Geißblog – Fan-nah und meinungsstark  
- Come-On-FC – Der FC-Blog
- Geißbockecho – Analysen
- Effzeh.com – Community
- Transfermarkt – Transfers & Gerüchte
- Express – Aktuelle Nachrichten
- KSTA – Lokalberichterstattung
- Kicker – Sportjournalismus

## Setup

```bash
npm install --cache /tmp/npm-cache
npm run dev
```

Build: `npm run build` → statischer Export nach `out/`
